## Goal
Create the first usable mobile shell that communicates the Pawssist experience.

## Included
- App shell
- Bottom navigation
- Home dashboard
- Pet profile preview
- Smart Scan entry point
- Care Vault overview
- Settings screen
- Mock data

## Not included yet

- AWS
- OCR
- AI integration
- Push notifications
