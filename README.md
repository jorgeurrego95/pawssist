# Pawssist v0.1

Pawssist is the intelligent pet care OS: scan records, track health, and receive proactive care guidance personalized to each pet.

## Current scope
- Expo + React Native mobile shell
- Pawssist brand theme
- Tab navigation
- Home dashboard
- Pet profile preview
- Smart Scan placeholder
- Care Vault placeholder
- Settings placeholder
- Mock data only, no backend yet

## Run locally
1. Open this folder in Cursor.
2. Run `npm install`.
3. Run `npm run mobile`.
4. Open with Expo Go or a simulator.

## Structure
- `apps/mobile` — Expo React Native app
- `apps/backend` — future NestJS API
- `packages/shared` — shared types
- `packages/theme` — shared design tokens
- `docs` — product and engineering notes
